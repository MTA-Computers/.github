## 📦 Tech Stack
- **Frontend:** Vue.js
- **Backend:** Laravel PHP
- **Database:** Mysql 

## 🛠 Installation

### Prerequisites
Ensure you have the following installed:
- Node.js & npm
- Vue CLI
- (Any other dependencies)

### Steps
1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/mta.co.ug.git
   cd mta.co.ug
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run serve
   ```
